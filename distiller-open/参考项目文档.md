## 核心参考项目

| 项目 | 仓库/来源 | 参考内容 |
|------|----------|---------|
| **mem0** | https://github.com/mem0ai/mem0 | Hub 内核 vs 应用层分层架构、单 schema + project_id 列隔离、append-only + supersede 版本链 |
| **Letta** | https://github.com/letta-ai/letta | memory_type 语义化分类（core/recall/archival）、三层上下文结构 |
| **Graphiti (Zep)** | https://github.com/getzep/graphiti | bi-temporal 有效期追踪（valid_from/valid_to）、episode 溯源链 |
| **Cognee** | https://github.com/topoteretes/cognee | 单 schema 租户隔离模式 |
| **Redis Agent Memory Server** | https://github.com/redis/redis-agent-memory | 双接口 REST + MCP 标准做法 |
| **Anthropic mcp-memory** | https://github.com/anthropics/anthropic-cookbook/tree/main/mcp/memory-server | JSONL 作为 source of truth 的极端简化设计 |
